# FENIX — Activity Book Studio

Rekonstruowana, samodzielna paczka projektu FENIX. Działa lokalnie bez serwera i bez instalacji zależności.

## Uruchomienie
1. Rozpakuj ZIP.
2. Otwórz `index.html` w Chrome, Edge lub Firefox.
3. Wybierz moduł, wygeneruj stronę i dodaj ją do Koszyka Feniksa.
4. Eksportuj Koszyk jako `.fenixpack`.

## Zawartość
- launcher i wspólny Koszyk Feniksa,
- 9 modułów activity-bookowych,
- lokalny eksport PNG,
- eksport pakietu `.fenixpack`,
- odzyskany kod MBG w `legacy/mbg-recovered.js`,
- standard biblioteki assetów i narzędzie audytujące.

## Ważne
To jest kompletna **rekonstrukcja robocza** przygotowana z dostępnych źródeł i pamięci projektu. Nie jest bitowo identyczna z ostatnią wersją, która mogła znajdować się lokalnie w Codexie. Odzyskany plik MBG zachowano bez zmian jako źródło legacy.
