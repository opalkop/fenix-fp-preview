# FENIX PC v0.14.0

## Najważniejsze zmiany

- nowy system projektów,
- osobny Koszyk Feniksa dla każdego projektu,
- tworzenie, edycja, przełączanie i usuwanie projektów,
- formaty 8,5 × 11, 6 × 9 i A4,
- ustawienie bleed / no bleed,
- grupa wiekowa i temat projektu,
- eksport aktywnego projektu jako `.fenixproject`,
- eksport Koszyka jako `.fenixpack`,
- migracja starego Koszyka do projektu „Odzyskany projekt”,
- jasny, ciemny i systemowy motyw interfejsu,
- odświeżony dashboard produkcyjny.

## Pobieranie

Pobierz repozytorium z gałęzi `main` przez GitHub: **Code → Download ZIP**.

Po rozpakowaniu uruchom plik `index.html`.
