# FENIX Asset Standard
- SVG: natywny `viewBox="0 0 1024 1024"`.
- Linie: czarne, czytelne, bez przypadkowych wypełnień.
- PNG: 300 DPI jako fallback.
- Nie skalować automatycznie starych 800×800 do 1024×1024, jeśli zmienia to grubość linii.
- Assety produkcyjne trafiają do `book-assets/svg`, `book-assets/png` lub `book-assets/packs`.
